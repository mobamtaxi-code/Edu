11주차 · 대화로 만드는 이미지 워크플로우

[시작] ZIP을 풀고 학생실습 폴더를 Codex 또는 Claude Code에서 작업 폴더로 열기.
요청문.txt는 메모장으로 열기. 필요한 단계의 ‘복사 시작~끝’만 채팅에 전송.
[대괄호]를 자기 내용으로 바꾸기. 폴더 경로는 탐색기 주소창에서 복사.

[제공 파일] 00_원본.png / 00_시작.psd / 영역마스크 폴더 / 과정정리_양식.pptx / 요청문.txt
[분리된 레이어] 원본 보존 + 하늘 + 왼쪽 수면 + 오른쪽 수면 + 건물 외피 + 유리면 + 중정 + 전경.
[영역마스크] 같은 7개 영역의 흑백 PNG. 흰 부분이 수정 대상. SD 등에서 부분 수정 범위를 지정할 때 필요에 따라 사용.
[PSD 열기] PhotoCraft에서 파일 → 열기 → 00_시작.psd. 미리 나눈 영역 레이어를 확인하고 사본으로 편집. 색·밝기를 바꿀 때는 해당 레이어의 이미지 썸네일을 선택(흑백 마스크 썸네일과 구분).
[주의] 경계는 사진을 보고 나눈 작업용 범위이며 정밀 자동 분할이 아님. PSD의 영역 구분은 원본 기준. 생성 결과의 구도가 바뀌면 선택 영역을 다시 확인. PSD는 실습용이며 제출하지 않음.
[작업 파일] 에이전트가 작업 폴더를 만들고 중간 결과를 v00.png, v01.png처럼 별도 저장.
[조건] 건축 외곽·중정·보행로 관계 유지 / 선택한 시간·계절 표현의 일관성.
[판단] 전략과 채택 이유는 학생이 결정. 수정 횟수·도구 개수는 자유.
